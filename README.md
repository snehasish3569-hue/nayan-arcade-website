# Nayan Arcade Website

A modern, responsive real-estate marketing website for Nayan Arcade, built using HTML, CSS and JavaScript.

## Project structure

- `index.html` — Homepage
- `about.html` — About page
- `projects.html` — Projects listing
- `project-details.html` — Reusable project detail page
- `contact.html` — Contact page
- `css/style.css` — Main design system and layout styles
- `css/responsive.css` — Responsive adjustments
- `js/main.js` — Shared functionality (nav, form validation, footer year)
- `js/projects.js` — Project data and dynamic rendering
- `sitemap.xml` — Sitemap
- `robots.txt` — Search engine instructions

## Deployment to GitHub Pages

1. Push this repository to GitHub.
2. In the repository, go to `Settings` → `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select the `main` branch and the `/root` folder.
5. Save the settings.
6. After a few minutes, your site will be published at:
   `https://snehasish3569-hue.github.io/nayan-arcade-website/`

## Custom domain setup

If you later add a custom domain:
1. Add the domain in GitHub Pages settings.
2. Create a `CNAME` file with the custom domain name, if required by your DNS provider.
3. Update your DNS records to point to the GitHub Pages IPs or the custom domain host.
